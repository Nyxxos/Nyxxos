About Me
<table><tr><td width="65%">

I'm Haroon, a Mechanical Engineering graduate from UCL, where I graduated with First-Class Honours. During my degree I became increasingly interested in robotics, mechatronics and AI, particularly where they can be used to solve real engineering problems.

I've worked on projects involving UAV design and testing, control systems, robotic path planning, soft robotics, computer vision and mechanical simulation. More recently, I've been developing my software and AI skills through Python, machine learning and generative AI projects.

Medical robotics is an area I'm especially interested in. I like the idea of bringing together mechanics, control, sensing and AI to build systems that can have a real-world impact. At the same time, I'm interested in opportunities across AI/ML, robotics, autonomous systems, mechatronics and engineering more broadly.

Right now, I'm building an <b>Intelligent Surgical Teleoperation Simulator</b> in Python and PyBullet as my first major independent robotics project, and I'm using this GitHub to document what I build and learn along the way.

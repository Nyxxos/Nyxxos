# About Me

<table>
<tr>

<td width="65%">

<p>
I'm Haroon, a First-Class Mechanical Engineering MEng graduate from UCL. I went into engineering because I liked understanding how things worked, but during my degree I found myself getting more interested in robotics, control and eventually AI.
</p>

<p>
My university work took me through quite a mix of areas: UAV design and testing, CFD and FEA, control systems, robotic path planning, soft robotics and computer vision. Since graduating, I've been spending more time on the software side and building up my Python, machine learning and generative AI skills.
</p>

<p>
Medical robotics is where a lot of those interests come together for me. It's one of the reasons I'm currently building a surgical teleoperation simulator in PyBullet. I'm still learning as I build it, and I want this GitHub to show that process rather than only uploading polished projects at the end.
</p>

<p>
I'm mainly interested in opportunities across robotics, AI/ML and mechatronics, especially where software has to interact with a real physical system.
</p>

# Currently Building

<table>
<tr>

<td width="65%">

<h2>Intelligent Surgical Teleoperation Simulator</h2>

<p>
This is the main project I'm working on at the moment. I'm building a teleoperation simulator from the ground up in PyBullet, starting with basic robot simulation and control before moving onto motion scaling, tremor filtering and safety constraints.
</p>

<p>
The point of the project is partly technical and partly practical: I want to get more comfortable building robotics software from scratch instead of only knowing the theory.
</p>

<h3>Current Progress</h3>

<ul>
  <li>PyBullet environment — complete</li>
  <li>Project structure and Git workflow — complete</li>
  <li>Robot model and joint control — in progress</li>
  <li>Inverse kinematics — next</li>
  <li>Teleoperation</li>
  <li>Motion scaling</li>
  <li>Tremor filtering</li>
  <li>Safety constraints</li>
  <li>Performance analysis</li>
</ul>
